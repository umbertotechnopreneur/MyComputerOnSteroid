# Support

MyComputerOnSteroid is a source bootstrap, not an installed launcher or supported
release. Start with [the build guide](docs/BUILD.md) and
[known verification limits](docs/VALIDATION.md).

Report reproducible bugs through
[GitHub Issues](https://github.com/umbertotechnopreneur/MyComputerOnSteroid/issues).
Include the commit, Windows build, architecture and exact failing command.
Use synthetic file names and remove personal paths from logs.

Feature discussions should describe the problem and expected behavior. Acceptance
of a proposal does not establish an implementation date.

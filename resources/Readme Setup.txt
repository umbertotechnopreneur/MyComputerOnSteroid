My Computer Enhanced - Setup guide
==================================

ENGLISH
Open This PC. Right-click My Computer Enhanced and choose Configure My Computer
Enhanced (Show more options if Windows displays its compact menu).
The same Configure command is available on empty space inside the launcher.
You can also use Configure My Computer Enhanced from the Start menu.

All configuration is in one window:
- This PC folders: Add new, choose a folder and icon, then Add. Select an existing
  entry to edit it and Save changes. Remove removes the registration, not files.
  Windows requests administrator permission only for these registration changes.
- Favorites: add a folder, app or file; select a shortcut to remove it or change
  its icon. These actions are immediate and never delete the original item.
- Search and view: search by name/path/extension, group, sort and edit extension
  families. Clear search removes the filter; press Apply to save preferences.
- Recent items: enable the section, set filters and press Apply. Restore hidden
  recent items is immediate. It does not modify the Windows history source.
- About: my website and the project's GitHub repository.

Apply saves Search and view and Recent items without closing the window.
Close discards unapplied preference edits. Other action buttons work immediately.
Folder and file pickers are ordinary Windows dialogs. Explorer's View menu still
controls icon size. Application text follows the Windows display language.
This guide is installed as an ordinary favorite shortcut in Files for the user
who installs the app. Removing its shortcut does not delete this installed file.
After an update, a loaded Shell extension may require an Explorer or Windows
restart. Finish file operations before restarting; installation does not force it.

ITALIANO
Apri Questo PC. Tasto destro su My Computer Enhanced > Configura My Computer
Enhanced (Mostra altre opzioni se Windows mostra il menu compatto).
Trovi lo stesso comando sullo spazio vuoto dentro il launcher, oppure il
collegamento Configure My Computer Enhanced nel menu Start.

Tutto è nella stessa finestra:
- Cartelle in Questo PC: Aggiungi nuova, scegli cartella e icona, poi Aggiungi.
  Seleziona una voce per modificarla e premi Salva modifiche. Rimuovi toglie
  solo la registrazione, mai cartelle o file. Queste modifiche richiedono UAC.
- Preferiti: aggiungi cartelle, app e file. Seleziona un collegamento per
  rimuoverlo o cambiarne l'icona. Queste azioni sono immediate.
- Ricerca e vista: ricerca, gruppi, ordinamento e famiglie di estensioni.
  Cancella ricerca toglie il filtro; premi Applica per salvare.
- Recenti: attiva la sezione, scegli i filtri e premi Applica.
  Ripristina recenti nascosti agisce subito, senza modificare la cronologia Windows.
- Informazioni: il mio sito e il repository GitHub del progetto.

Applica salva Ricerca e vista e Recenti senza chiudere la finestra.
Chiudi scarta le preferenze non applicate. Gli altri pulsanti agiscono subito.
Il menu Visualizza di Explorer continua a controllare la dimensione delle icone.
La lingua dell'app segue quella di Windows. Il collegamento a questa guida e
aggiunto ai File del launcher per l'utente che installa il programma.
Dopo un aggiornamento può servire riavviare Explorer o Windows: termina prima
copie e spostamenti. L'installazione non forza il riavvio.

TIẾNG VIỆT
Trong This PC, nhấp chuột phải vào My Computer Enhanced > Cấu hình My Computer
Enhanced. Nếu cần, chọn Show more options. Các thẻ gồm thư mục trong This PC,
yêu thích, tìm kiếm và hiển thị, gần đây, giới thiệu. Bấm Áp dụng để lưu tùy chọn
tìm kiếm/hiển thị và gần đây. Xóa chỉ bỏ lối tắt, không xóa mục gốc.

FRANÇAIS
Dans Ce PC, clic droit sur My Computer Enhanced > Configurer My Computer
Enhanced (Afficher plus d'options si nécessaire). Les onglets regroupent les
dossiers Ce PC, favoris, recherche/affichage, récents et informations.
Appliquer enregistre les préférences recherche/affichage et récents.
Supprimer retire uniquement la reference, jamais le dossier ou fichier original.

DEUTSCH
Unter Dieser PC: Rechtsklick auf My Computer Enhanced > My Computer Enhanced
konfigurieren (gegebenenfalls Weitere Optionen anzeigen). Alle Einstellungen
stehen in Registerkarten: Dieser PC, Favoriten, Suche/Ansicht, zuletzt verwendet,
Info. Anwenden speichert Suche/Ansicht und zuletzt verwendet. Entfernen betrifft
nur die Verknüpfung oder Registrierung, niemals Originaldateien.

ESPAÑOL
En Este equipo, clic derecho en My Computer Enhanced > Configurar My Computer
Enhanced (Mostrar más opciones si es necesario). Las pestañas contienen carpetas,
favoritos, búsqueda/vista, recientes e información. Aplicar guarda búsqueda/vista
y recientes. Quitar elimina solo la referencia, nunca los archivos originales.

简体中文
在“此电脑”中右键单击 My Computer Enhanced，然后选择“配置 My Computer Enhanced”。
如有需要，先选择“显示更多选项”。也可以在启动器的空白处找到配置命令。
所有设置位于同一个窗口的标签页：文件夹、收藏夹、搜索和视图、最近使用、关于。
点击“应用”保存搜索、视图和最近项目设置。移除只会删除引用，不会删除原始文件。

香港粵語
喺「本機」右擊 My Computer Enhanced，再揀「設定 My Computer Enhanced」。
有需要就先揀「顯示更多選項」。啟動器空白位置都有同一個設定選項。
資料夾、我的最愛、搜尋同檢視、最近項目同關於，全部都喺同一個視窗入面。
按「套用」儲存搜尋、檢視同最近項目設定。移除只會刪除引用，唔會刪除原本嘅檔案。

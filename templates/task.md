## MCS-NNN - Concrete task title

**State:** open / implemented awaiting delivery / delivered.

**Problem:** describe the observable problem.

**Completion condition:** describe the resulting behavior and necessary evidence.

**Scope:** identify affected components and user-data operations.

**Validation:** record actual checks, architectures and unverified behavior.

**Delivery:** link the commit or pull request after delivery. Keep pending work
in todo.md, implementation awaiting delivery in done.md and delivered records
in archive.md. Do not duplicate complete command transcripts.

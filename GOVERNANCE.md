# Governance

I am Umberto Giacobbi, the maintainer and copyright holder of MyComputerOnSteroid.
My public publisher identity is [umbertogiacobbi.biz](https://umbertogiacobbi.biz).
I decide product scope, accept contributions and choose releases.

The project participates in the VibeWare movement. VibeWare does not publish,
manufacture or certify this project. The project name, package metadata and
copyright notices must keep that distinction.

The repository uses MIT. There is no separate commercial-use restriction and no
contributor license assignment requirement. Contributors retain their applicable
copyrights and provide their contributions under the repository license.

After the initial repository bootstrap, code changes go through pull requests.
Required checks and review conversations must be resolved before squash merge.
Repository publication, binary releases, installation and runtime verification
are separate actions. A successful build is not a release.

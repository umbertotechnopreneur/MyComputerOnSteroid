# Security

This project is an early native Shell provider. There are no released or
security-supported versions yet. Compilation does not establish that loading
the extension into Explorer is safe or that its planned behaviors work.

For a suspected vulnerability, use the repository's private
[security reporting page](https://github.com/umbertotechnopreneur/MyComputerOnSteroid/security/advisories/new).
If private reporting is unavailable, use the contact information on
[my website](https://umbertogiacobbi.biz). Do not post private file paths,
credentials, personal documents or exploit payloads in a public issue.

Include the commit, Windows version, architecture and a minimal reproduction
using synthetic files. No response-time or remediation guarantee is implied.
